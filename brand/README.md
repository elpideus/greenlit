# Greenlit brand kit

The files here are Greenlit's own artwork. The full rules (colour roles, type scale, motion, layout, copy) are in
[docs/DESIGN.md](../docs/DESIGN.md); this page is the short version for anyone making something *about* Greenlit.

## Idea

*Greenlit* is the moment a piece of work is approved and goes out. The mark is a **signal with two lamps**: the upper
one holds, the lower one lights green. The same lamp runs through the whole product — tally lights on every item,
the signal beside the decision buttons, semaphore toggles — so the logo is never decoration.

## Files

| File | Use |
| --- | --- |
| `greenlit-mark-on-dark.svg` / `-on-light.svg` | the mark in colour (off-white or graphite housing, green lamp) |
| `greenlit-mark-white.svg` / `-black.svg` | one-colour mark |
| `greenlit-wordmark-on-dark.svg` / `-on-light.svg` / `-black.svg` | "Greenlit" in Geist; the *i*'s dot is the green lamp |
| `greenlit-lockup-on-dark.svg` / `-on-light.svg` | mark + wordmark |
| `greenlit-app-icon.svg` | app icon / favicon: the mark on a graphite tile (22% radius) |

Minimum size 14 px for the mark. Clear space: one lamp diameter on every side. Don't recolour the housing, outline,
stretch or rotate the mark (the semaphore toggle is the mark on its side by design), and don't put the green lamp
on a colour other than graphite, off-white or a dark photo.

## Colour

| | Dark | Light |
| --- | --- | --- |
| Graphite (ground) | `#0C0D0C` | `#F5F7F6` |
| Ink | `#EDEFED` | `#141715` |
| **Signal green** | `#42D77B` | `#007F3D` |
| Review amber | `#F9B73F` | `#A35F00` |
| Changes red | `#F75D59` | `#C52C2A` |
| Cue blue | `#6AA7F4` | `#1C65C8` |

Green is a signal, not decoration: the one commit action, selection, the lit lamp.

## Type

Geist (600 for titles, 650 at display sizes with −0.055 em) and Geist Mono for numbers. Sentence case.

## The composition

Flat blocks of the signal colours on graphite: a tall green column holding two graphite signals, a pale panel with
one signal, an amber tile with one rounded corner, a small blue square, and "Greenlit" set huge beside them. No
gradients; the only glow is a lit lamp's. The sign-in page is the reference.

## Voice

Plain, short, specific. Say what happens ("Sent to Giulia for review"), never what someone did wrong. No exclamation
marks, no emoji.
